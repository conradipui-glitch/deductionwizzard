# Дело № 2 — происхождение образов богов

**Статус:** исследовательский пилот. Не доказательство единой гипотезы.

## Постановка
Изучаем ранний культ Яхве и Ашеры; обожествление правителей; распространение сюжетов; возможность независимой конвергенции; отдельно — гипотезу древних технологических визитов.

- `casebook.json`: каноническая схема Deduction Wizard 1.0, 9 источников, 11 утверждений, 9 контекстов, 6 конкурирующих гипотез и 15 объяснённых оценок.
- `comparisons.json`: четыре **кандидатных** межкультурных сопоставления.
- `tests/test_gods_case.py`: структурные тесты и защиты от превращения интерпретации в факт.

## Методологические ограничения
1. Существование надписи/литературного текста **не доказывает** истинность сообщённого события.
2. Дата памятника **не является** датой события, описанного памятником.
3. Два музейных/научных комментария к одному артефакту — один корень свидетельства.
4. `attested` означает только, что текст/изображение содержит обозначенный мотив. Гипотезы об историческом Яхве-правителе и древней технике остаются `unverified`.
5. «Не проверено» и «не доказано» не тождественны «опровергнуто».
6. Сходные имена, изображения и символы сами по себе не устанавливают идентичность персонажей.
7. Точные даты авторства эпосов, локаторы строк и варианты переводов ещё нуждаются в независимом аудите. Диапазоны BCE приблизительны; нулевой год не используется.

## Проверка
```bash
PYTHONPATH=packages/deduction-core/src python -m historicdeductionsim validate cases/gods/casebook.json
python -m unittest discover -s tests -v
```

## Интеграция
Это **data-only** исследовательская ветка. UI сейчас импортирует только `cases/pushkin/casebook.json` и использует подготовленные сцены Пушкина. Переключатель дел, редактор и новый StoryReader не добавлялись, чтобы не менять стабильный интерфейс. Код/секреты/основная ветка не затронуты.
